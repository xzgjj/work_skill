```
1. MCP FIRST — 任何数据采集，第一发必须打向 MCP 工具，不允许跳过

### 🔬 高价值参考收集 — Exa搜索中主动抓取

**搜索结果中如果出现以下类型的高价值材料，必须单独标注并融入分析：**

| 材料类型 | 识别特征 | 使用方式 |
|----------|---------|---------|
| **行业研究报告** | Counterpoint/TrendForce/IDC/Gartner/IC Insights/TechInsights 等 | 竞争格局、市场份额、技术趋势 → 优先采信 |
| **技术分析报告** | SemiAnalysis/Silicon Analysts/AnandTech/专利分析 等 | 制程/良率/技术路线 → 作为技术视角的核心数据源 |
| **卖方深度研报** | 高盛/摩根士丹利/野村/中金/华泰/各大券商 等 | 估值模型、盈利预测、目标价 → 交叉验证 |
| **公司官方材料** | SEC 6-K/年报/季报/Earnings Call Transcript | 财务数据、管理层指引、产能计划 → 直接引用 |
| **监管文件** | 韩国交易所公告/FSS申报/国家统计局数据 | 官方数据 → 最可靠来源 |
| **学术/智库研究** | KIET/KEIA/PIIE/大学研究报告 | 产业政策、结构性分析 → 深度分析引用 |

> ⚠️ 原则：机构报告 > 新闻报道 > 自媒体。同等信息时优先引用机构报告。在"独立验证"模块中标注哪些数据来自机构报告、哪些来自新闻报道。

### L1.5: Chrome DevTools 降级 — Exa 任一路失败后立即触发

```
Exa某维度失败/超时/返回空 →
  Bash: mcporter call chrome-devtools.navigate_page type="url" url="https://www.bing.com/search?q=<URL编码后的搜索词>"
  Bash: mcporter call chrome-devtools.evaluate_script function="() => { const results = document.querySelectorAll('#b_results .b_algo h2 a'); return Array.from(results).slice(0, 5).map(a => ({title: a.textContent, url: a.href})); }"
```

**Chrome DevTools 需要分两步（navigate + evaluate），失败维度逐一重试，不重发全部。**

```
Exa维度3"研报"失败 → Chrome DevTools只补维度3
Exa维度5"技术"失败 → Chrome DevTools只补维度5
```

### 🚫 禁止路径 — 以下行为绝对不允许

```
❌ 第一步就用 Exa/Bing/Google 搜索                           → 必须先打 MCP
❌ 第一步就用 WebFetch 抓取网页                               → 必须先打 MCP
❌ 第一步就用 Bash curl/http 请求                             → 必须先打 MCP
❌ MCP 失败后自己编造/回忆数据                                → 走降级链
❌ MCP 失败后跳过 Exa 直接用 Chrome DevTools/CCS WebSearch     → Exa 是 L1
❌ Exa 失败后不试 Chrome DevTools 直接放弃                     → Chrome DevTools 是 L1.5
❌ 说 "TradingView 不可用, 我用搜索代替" 而不实际调用 MCP      → 必须先尝试调用
❌ 并行发 MCP + 搜索, 然后只用搜索结果忽略 MCP 返回值          → MCP 结果优先
❌ 发现高价值机构报告但不引用，只用新闻文章                    → 机构报告优先于新闻
```

### 降级链总览

```
L0: MCP stock-scanner (并行全发)
  ↓ 任一回失败
L1: Exa web_search_exa (7维度并行·B类 / 6维度并行·C类)
  │  ↳ 搜索中主动收集：行业报告 + 技术报告 + 卖方研报 + 官方材料
  ↓ 任一维度失败
L1.5: Chrome DevTools → Bing搜索 + 提取结果 → 只补失败维度
  ↓ Chrome DevTools不可用
L2: CCS WebSearch → 最后手段
```

### MCP 返回后 — 数据完整性检查

MCP 返回后，检查以下字段是否都有有效值：

```
✓ 实时报价 (price/close/current)     → 缺 → Exa 补
✓ 涨跌幅 (change/change_pct)          → 缺 → Exa 补
✓ 成交额/成交量 (volume)               → 缺 → Exa 补
✓ 市值 (market_cap)                    → 缺 → Exa 补
✓ 技术指标 (RSI/MACD/MA)              → 缺 → Exa 补
✓ 大盘指数 (上证/深证/创业板)          → 缺 → Exa 补
✓ 财务数据 (营收/利润/ROE)             → 缺 → Exa 补
```

### TECH 数据完整性检查（仅当触发 TECH 模块时）

```
✓ 制程/技术指标 (process node/yield/tech generation)     → 缺 → Exa 补
✓ 产品量价 (shipment/ASP/capacity utilization)             → 缺 → Exa 补
✓ 产能数据 (wafer starts/capacity/fab timeline)            → 缺 → Exa 补
✓ 客户结构 (top customers/revenue concentration)           → 缺 → Exa 补
